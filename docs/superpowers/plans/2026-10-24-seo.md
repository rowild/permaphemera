# SEO for every page — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every route of permaphemera.at carries its own title, description, share image, canonical, hreflang and JSON-LD, edited in Directus with the Directus Labs SEO plugin and delivered to crawlers through per-route HTML snapshots written at deploy.

**Architecture:** One pure module (`frontend/shared/seo.mjs`) turns the raw archive snapshot plus the locale messages into one SEO entry per route and locale. The Nuxt pages apply an entry through `usePageSeo`; the deploy script imports the same module and writes `<route>/index.html` (the SPA shell with that head), `sitemap.xml` and `robots.txt`. Directus gets a `seo` JSON field (plugin interface) on five collections and their translation tables.

**Tech Stack:** Directus 11.17.4 + `@directus-labs/seo-plugin`, Nuxt 4 SPA (`ssr: false`), `@nuxtjs/i18n` (`de` unprefixed, `en` under `/en/`), Vitest, Node 24 scripts, nginx `try_files $uri $uri/ /200.html`.

**Spec:** `docs/superpowers/specs/2026-10-24-seo-design.md`

## Global Constraints

- Site URL `https://permaphemera.at`; German paths unprefixed, English under `/en/`; every path ends with `/`.
- Title at most 60 characters in total; a stored `seo.title` is used verbatim; generated titles add ` · PERMAPHEMERA` only when the result stays ≤ 60.
- Description: stored `seo.meta_description` verbatim, else generated and cut at a word boundary to ≤ 160 characters, HTML stripped.
- Share image: `seo.og_image`, else the record image, as `<asset>?width=1200&height=630&fit=cover&format=jpg&quality=80`.
- Per-language `seo` holds only `title` and `meta_description`; `og_image`, `no_index`, `no_follow`, `sitemap` come from the record's `seo` for both languages.
- A record without a German translation: German entry uses the English text, stays indexable, hreflang lists both.
- Texts plain and factual, no metaphors or praise words (owner rule); say "exhibition", never "show".
- Schema changes only through `directus/scripts/schema.mjs` (+ `fields.mjs`/`build.mjs`), applied with `create-schema.mjs`; same commit updates `frontend/app/types/content.ts` and `_Plans/exhibitions-plan.md` §2.
- Production Directus is live data; run every schema step locally first.

## Review Focus

- An exhibition with a placeholder image, or without a published venue/town, has no entry (its page is a 404) — test in Task 3.
- A title or description containing `"`, `&`, `<` or `</script>` is escaped in the snapshot head and in the JSON-LD — test in Task 5.
- `seo.no_index` on the record yields `noindex` on both locales and drops the route from the sitemap, but the snapshot is still written — test in Tasks 3 and 5.
- A person or venue without a German translation still gets a German entry with English text — test in Task 3.
- A stored `seo.title` longer than 60 characters is used as written (the owner decided), while a generated one is never longer than 60 — test in Task 3.
